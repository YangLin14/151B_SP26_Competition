# CSE 151B QLoRA command reference

Use the platform-specific Markdown docs in `docs/`.

```text
Native Windows / PowerShell:
docs/QLORA_WINDOWS_POWERSHELL.md

DSMLP / Linux / WSL / Bash:
docs/QLORA_DSMLP_BASH.md

QLoRA training/results tracker:
docs/QLORA_RESULTS_TRACKER.md

High-level QLoRA workflow:
docs/qlora_workflow.md
```

Markdown is preferred over `.txt` for command references because it supports
shell-specific fenced code blocks, headings, and readable warnings.

Key differences:

```text
Windows PowerShell line continuation: `
Linux/DSMLP Bash line continuation: \
Windows paths: outputs\...
Linux/DSMLP paths: outputs/...
Windows eval backend: Transformers
Linux/DSMLP eval backend: vLLM
Native Windows: do not install or run vLLM.
Python 3.13 is not OK for the pinned PyTorch stack. Use Python 3.11.
```
