Before Running the Notebook:

Don't run the setup cells in the Notebook.

cd to current project folder.

Create environment:
uv venv .venv --seed

Activate venv:
source .venv/bin/activate

Install depedencies:
uv pip install torch==2.5.1 torchvision==0.20.1 torchaudio==2.5.1 --index-url https://download.pytorch.org/whl/cu121
uv pip install sympy numpy transformers vllm tqdm bitsandbytes antlr4-python3-runtime==4.11.1 ipykernel jupyter accelerate peft trl datasets -c constraints.txt
